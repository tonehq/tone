# Sarvam TTS — Voice & Model Reference

> **Last updated:** 2026-03-27
> **Source:** Official Sarvam AI documentation

---

## Key Rules

- **Speakers are model-specific** — zero overlap between v2 and v3
- **All speakers support all 11 languages** — no language restriction
- Speaker name determines the model

## Notes

- bulbul:v3 supports `pace` and `temperature` controls
- bulbul:v2 supports `pitch`, `pace`, and `loudness` controls
- bulbul:v3 does NOT support `pitch` or `loudness`
